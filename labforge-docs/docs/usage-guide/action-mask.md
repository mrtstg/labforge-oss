# Использование маски действия

Маска действия - специальное выражение, которое ограничивает список виртуальных машин, к которым действие будет применено. На текущий
момент маска может действовать как исключение виртуальных машин или создание списка

Чтобы включить все виртуальные машины, оставьте поле пустым или укажите `*`.

## Синтаксис

Для включения виртуальной машины в список, напишите ее название. Например:

```
A B C
```

Будет означать, что действие будет применено к виртуальным машинам с именами A, B и C. Для исключения виртуальной машины
укажите ее имя с восклицательным знаком в начале, например:

```
!A !B C
```

Будет означать, что действие будет применено ко **всем** виртуальным машинам кроме A и B. Обратите внимание, что в таком случае
нотации о включении виртуальных машин будут игнорированы.
