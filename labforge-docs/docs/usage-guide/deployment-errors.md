# Определение ошибок развертывания

## Базовая проверка

В первую очередь, стоит проверить логи развертывания - они доступны со страницы стенда пользователя для администратора
и создателя шаблона стенда. Обычно ошибки вызываются неправильно настроенной конфигурацией или инфраструктурными проблемами.

В случае, если логов нет или они несодержательны, скопируйте из ссылки
идентификатор стенда для следующего пункта. Например, в ссылке `https://labforge.mrtstg.local/instance/67804970-bdb3-42d0-bde6-a91ce99ef7f5-5`
идентификатор это `67804970-bdb3-42d0-bde6-a91ce99ef7f5-5`.

## Если на странице развертывания нет логов

Если обладаете доступом, воспользуйтесь [системой мониторинга](./monitoring.md) и поищите логи по идентификатору стенда в контейнере
`labforge-jobservice`. Скорее всего, вы найдете ошибку или ошибочный ответ от других сервисов здесь

## Очистка проблемных стендов

В большинстве случаев хватит вызова персонального удаления стенда, **массовый вызов удаления игнорирует ошибочные стенды.** Если этого не хватило,
свяжитесь с разработчиками.
