# Общие требования для запуска

## Системные требования

!!! note "Примечание"

    Текущие требования выявлены синтетическими тестами системы и могут быть неточны в ряде сценариев использования. Параметры памяти и CPU предполагают минимальное использование ресурсов системой и отсутствие других высоконагруженных процессов. Параметр дискового пространства может варьироваться от использования системы и включает в себя расчет на загрузку и хранение данных установщика.


| Параметр | Минимальное требование | Рекомендуемые требования |
|----------|------------------------|--------------------------|
| CPU | 6 ядер, 2.6 ГГц | 8+ ядер, 2.6 ГГц
| RAM | 6GB | 8GB+ |
| Свободное дисковое пространство | 30GB | 40GB |


## Программные требования

Для базовой установки на одном сервере требуется:

1. Произвольный дистрибутив Linux (протестированы: Debian 11, Debian 13, RedOS Server 8)
2. Установлен Docker Engine версии 28.X.X или выше, Docker Compose plugin версии 2.34.0 или выше
3. Установлены пакеты `make`, `jq`, `openssl` (в случае генерации сертификатов установщиком)
4. Пользователь для выполнения команд должен иметь право выполнять команды `docker` без повышения привилегий (наличие пользователя в группе `docker`)
5. Пользователь для выполнения команд имеет право эскалации прав до суперпользователя при помощи `sudo`

## DNS-записи

Требуется две DNS-записи A-типа для интерфейса системы и системы авторизации (Keycloak). Стандартные рекомендации для записей:

- `labforge.<domain>` для интерфейса
- `auth.<domain>` для системы авторизации

## Требования к Proxmox

Версия PVE: 8.4+

При использовании нескольких хостов:

- Хосты находятся в одном кластере
- Шаблоны VM, которые будут использоваться находятся на shared хранилище для общей доступности по одному VMID

### Использование Альт Виртуализации

На текущий момент протестирована **Альт Виртуализация 11.0 (редакция PVE)**

Протестированные кейсы:

1. Развертывание и удаление Simple SDN сетей (до 500)
2. Развертывание системы без дополнительного разделения доступа при помощи встроенного Firewall
3. Тестирование общего функционала Labforge

**Стабильная работа версии гипервизора при массовом развертывании на текущий момент не проверялась, но ожидается.**
