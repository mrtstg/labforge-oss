# Конфигурация сервисов

Сервисы конфигируются посредством переменных окружения. Также, при запуске сервисы пытаются загрузить файл `.env`, если он есть.

## Связь сервисов

Для связи между сервисами используются две переменные: `<NAME>_URL` и `<NAME>_IGNORE_SSL`. Первая переменная отвечает за
базовый URL сервиса, второй - будет ли проверяться сертификат при HTTPS соединении
