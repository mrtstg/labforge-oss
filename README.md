# labforge-oss

Открытая платформа для автоматического развертывания стендов Proxmox в образовательном контуре

## Структура проекта

Проект представляет собой микросервисную платформу, которая включает в себя самостоятельно
разработанные компоненты, а также другие Open-Source проекты (Keycloak, nginx, и.т.д)

## Документация

Основная информация расположена в каталоге `labforge-docs` в виде mkdocs-проекта, который можно запустить при помощи команд:

```bash
poetry install --no-root # потребуется пакетный менеджер Poetry
poetry run mkdocs serve
```

Также документация идет в комплекте nginx-образа дистрибутива и доступа по [данной ссылке](https://labforge.mrtstg.ru).
